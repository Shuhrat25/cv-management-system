# Подключение Salesforce и Odoo

В репозитории подготовлен код интеграций. Успешная проверка с настоящими внешними аккаунтами пока не выполнена: прежний адрес Salesforce org недоступен, а работающий экземпляр Odoo ещё не выбран. Power Automate оставлен без изменений.

## Salesforce

По умолчанию используется OAuth client credentials. На стороне Salesforce нужна действующая org и External Client App с разрешённым этим flow, назначенным integration user и минимальными правами API. Прежний password flow доступен только при явно заданном `SF_AUTH_FLOW=password`.

Серверное окружение:

| Переменная | Значение |
| --- | --- |
| `SF_ENABLED` | `true` после подготовки реальной org |
| `SF_LOGIN_URL` | HTTPS My Domain вашей org, без `/services/oauth2/token` |
| `SF_CLIENT_ID`, `SF_CLIENT_SECRET` | Параметры External Client App; только на backend |
| `SF_AUTH_FLOW` | `client_credentials` (по умолчанию) |
| `JWT_SECRET` | Собственное случайное значение длиной минимум 32 символа |
| `INTEGRATION_OPERATOR_IDS` | UUID выделенных администраторов приложения, через запятую |
| `SF_WRITES_ENABLED` | Оставить `false` для проверки соединения |
| `SF_VERIFY_ON_START` | `true` для read-only проверки при запуске backend |

Создайте отдельную обычную учётную запись TalentPulse с собственным паролем, затем администратор БД должен приватно назначить ей роль ADMIN и добавить её UUID в `INTEGRATION_OPERATOR_IDS`. Публичная регистрация не выдаёт ADMIN. Учебные `john`, `mary`, `sarah`, `admin@example.com` не являются операторами интеграций, включая старые сессии. Одного повышения роли через учебный административный интерфейс недостаточно.

После входа выделенного оператора `GET /api/external/salesforce/test-auth` получает токен и выполняет read-only запрос Salesforce `/limits`; токен клиенту не возвращается. Доступ без входа или из demo-сессии отклоняется. Только после успешной проверки и отдельного решения о передаче данных следует разрешать запись. `POST /api/external/salesforce/create-contact` экспортирует профиль самого оператора; Account и Contact создаются атомарным Composite запросом. Автоматической синхронизации всех кандидатов нет.

Дополнительно `SF_VERIFY_ON_START=true` выполняет ту же проверку внутри backend при старте и пишет в серверный журнал только результат без токенов. Сбой необязательной CRM не останавливает самостоятельное учебное демо.

Код ограничивает время запросов, кэширует токен и не возвращает сырые ошибки/секреты Salesforce. Это не устраняет остальные ограничения учебной платформы. Публичный demo ADMIN управляет пользователями приложения: не загружайте в эту демонстрационную базу реальные персональные данные кандидатов и не используйте её как production IAM.

[Salesforce: client credentials](https://help.salesforce.com/s/articleView?id=xcloud.remoteaccess_oauth_client_credentials_flow.htm&language=en_US&type=5).

## Odoo Community

Существующий замысел — Odoo забирает JSON-агрегаты вакансии из TalentPulse. В `odoo_addons/talentpulse_connector/` добавлен модуль для **Odoo Community 19.0**: административная запись настроек, маскированный токен вакансии и ручная загрузка результатов. Модуль сохраняет только сводку и агрегаты, без персональных CV, не создаёт cron и не отправляет записи обратно.

Нужен отдельный работающий сервер Odoo Community с PostgreSQL. Установка описана в [README модуля](../odoo_addons/talentpulse_connector/README.md). Сам модуль ещё не установлен в реальный Odoo; ORM, представления и обмен требуют проверки по указанному там чек-листу.

Токен вакансии больше не выдаётся публичными/demo-ответами TalentPulse. Получать его может настоящий владелец или выделенный оператор. Перед включением обмена установите `ODOO_ENABLED=true` и приватный `JWT_SECRET` длиной минимум 32 символа. Ранее опубликованные токены следует заменить перед использованием реальных данных; скрытие из ответа не отзывает ранее раскрытый токен.

Odoo Online **One App Free** и **Standard** не включают внешний API; Online не поддерживает установку этого Python-модуля. Community бесплатна по лицензии, но сервер и его эксплуатация нужны отдельно. Платная подписка в этой работе не создавалась.

[Odoo: внешний API](https://www.odoo.com/documentation/19.0/developer/reference/external_api.html), [Odoo Online](https://www.odoo.com/documentation/19.0/administration/odoo_online.html).

## Что проверено

TypeScript-сборки backend/frontend, тесты доступа и OAuth с подставными ответами Salesforce, тесты скрытия токенов, Python-тесты клиента Odoo и статическая проверка модуля. Это проверки кода; они не заменяют авторизацию в настоящей Salesforce org и запуск модуля в настоящей базе Odoo.
